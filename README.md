# Pryyz art

Painted artwork used by the Pryyz game, from the Fantasy Game Graphics pack (WebP).

- `icons/items/<item id>.webp`: 128px item icons, one per game item (139). Recoloured variants are baked in.
- `textures/<material>.webp`: 512px repeating ground textures (10).

The game copies these into `client/icons/items/` and `client/textures/`.
